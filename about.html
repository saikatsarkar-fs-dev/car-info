About · The field notes

A small site with a clear brief.

Car/Info is a college assignment about six popular Indian cars, built to show what hand-written HTML and CSS can do without a framework, a build step or a line of JavaScript.

Project notes Data: Oct 2026

01 / The brief

Learning by documenting.

The assignment was simple: build a multi-page car information website using current HTML and CSS standards.

The interesting part was the constraint. No JavaScript, no framework and no build step means every interaction has to be earned with HTML and CSS. The filter on the garage page is a set of radio inputs and a :has() selector. The light and dark themes come from the operating system. The comparison table scrolls with the keyboard. Nothing is simulated.

The six cars were chosen to cover the market rather than a single niche: a hatchback, a sedan, three SUVs and an off-roader, with prices from under ₹6 lakh to over ₹50 lakh. Specifications are checked against manufacturer pages, with receipts on every car page.

02 / The method

Hand-written, on purpose.

The site uses current platform features, but every page still works if the newest ones are missing.

The HTML comes first: landmarks, heading order and real links. The CSS is organised in cascade layers so the reset, design tokens, base styles, layout and components do not fight each other. There is no utility-class soup and no build pipeline to reproduce.

The result is a static folder you can open on a laptop, serve from GitHub Pages or archive for a submission. The README explains how to run it and how to add another car.

  1. Semantic HTML

    Landmarks, one h1 per page, hgroup for page heads, search for the filter, figure and figcaption for every photo, details for sources, and tables with captions and scoped headers. Detail pages carry JSON-LD Car data.

  2. CSS with layers

    One stylesheet, six cascade layers, custom properties and fluid clamp() spacing. Colours use oklch() with hex fallbacks, light-dark() for system themes and color-mix() for tints. A container query adapts the card meta on very narrow screens.

  3. Progressive enhancement

    No JavaScript, no framework, no build step. The CSS filter only appears when :has() is supported; otherwise every car stays visible. Cross-document view transitions are optional. Images have width and height attributes to avoid layout shift.

  4. Accessibility

    Skip link, visible focus styles, reduced-motion support, descriptive alt text, labelled landmarks and a keyboard-scrollable table region. Text and background colours are chosen to stay readable in both colour schemes.

03 / The data

How the numbers were checked.

Manufacturer pages were the first stop. Where a manufacturer publishes only a starting price, the top-end figure came from CarWale's October 2026 listing. Tata Motors' official site blocks automated requests, so the Nexon's figures were cross-checked against CarWale and CarDekho.

Prices are ex-showroom and vary by city. Specifications vary by variant and model year. Nothing here is a substitute for a test drive, a written quote or the owner's manual. If a number is wrong, send the car, variant and a source; corrections are welcome.

04 / Access

Built to be used.

The site has no JavaScript, so every page works with scripting disabled and every link is a real link.

Keyboard focus is visible. The comparison table can be scrolled with the keyboard. Motion is disabled when the operating system asks for reduced motion. Light and dark themes follow the system setting, with contrast checked in both.

Every photograph has descriptive alt text, and the decorative SVG icons are hidden from assistive technology. The navigation is a list of ordinary links, not a scripted menu.

  • Skip link and semantic landmarks on every page.
  • Visible :focus-visible styling on links, buttons and form controls.
  • Keyboard-scrollable, labelled comparison table region.
  • Reduced-motion support for every animation and transition.
  • Automatic light and dark themes using color-scheme and light-dark().
  • Descriptive alt text and visible photo credits.

Known limitations. The CSS body-style filter changes what is visible but does not announce a result count to screen readers. Every car remains in the document and is reachable when the filter is not used. The filter is hidden in browsers without :has() support. External images need an internet connection.
